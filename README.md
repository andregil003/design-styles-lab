# Design Styles Lab 🎨

Galería de **17 estilos de diseño nicho** con demos vivas 100% offline (CSS/SVG puro, cero imágenes externas) + receta de prompt reutilizable por estilo.

Ver en vivo: https://andregil003.github.io/design-styles-lab/ (GitHub Pages, público).
